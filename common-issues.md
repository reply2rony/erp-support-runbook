# Common ERP Support Issues (Template)

## 1. User cannot sign in
- Check: account exists, account is not locked, password is correct, correct role assigned.
- Fix: reset password per policy, unlock account, confirm role with the manager.

## 2. User cannot see a screen or button they need
- Check: role and permissions for that screen.
- Fix: correct the role only with manager approval. Do not give admin rights to fix a permission problem.

## 3. Data looks wrong (stock, price, balance)
- Check: was the entry made correctly? Is it a display/filter problem or a real data error?
- Fix: correct only with approval, and record the old value, new value, who approved it, and when.

## 4. System is slow or not responding
- Check: is it one user or everyone? Is the server/network available?
- Fix: follow the network playbook, then escalate to the vendor if the system itself is down.

## 5. Report or print does not work
- Check: report filters, date range, printer, and user permissions.
- Fix: test the same report with a sample filter, then check the printer separately.
