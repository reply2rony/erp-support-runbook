# ERP Support Runbook and Incident Log

A runbook for supporting a business (ERP) system, and a log for recording every incident the same way. This is a template — replace "Sample ERP" with your real system name only in your own private copy, never with real company data in a public repository.

## Files
- `erp-runbook.md` — the first-response steps for ERP problems.
- `common-issues.md` — the most common ERP support issues, in plain language.
- `incident-log-template.csv` — one row per incident, so patterns can be seen over time.
